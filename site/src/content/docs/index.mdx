<CardGrid>
	<Card title="Positions, held by people and agents" icon="puzzle">
		Each position has a canonical name, the system it answers for, an owner and a mandate. Its holder is a person
		or an agent session; when a session is replaced or moves to another account, the position stays and only its
		holder changes.
	</Card>
	<Card title="One window for you" icon="comment">
		Your conductor is the first agent you start. You talk to it, and it takes each request to its owner. Agents
		ask you on cards, with options and a recommendation, never in a pane you are not looking at.
	</Card>
	<Card title="Every session recorded" icon="document">
		Hooks record every Claude Code session as typed events in your organization's own store. Raw traces leave
		your machine only with your consent, per organization.
	</Card>
	<Card title="A guard before every tool" icon="approve-check">
		Reading secret files, printing secrets and reading process memory are denied before the tool runs. A secret
		that reaches a transcript anyway is masked, and can be removed from every stored copy.
	</Card>
</CardGrid>

## Where it stands

Organic Framework is early. Today it runs the team that builds it and one user organization, on
[herdr](https://herdr.dev) and Claude Code, on macOS and Linux. Each feature's state, with its evidence, is in
[What works today](features/).
