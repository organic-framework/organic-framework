## Rules

1. **Count the records, not the status notes.** Each item's state comes from what exists: a commit, a registry
   entry, an answered ask, a register row with a source, a live holder (`of who`), an event.
2. **Green only with its own evidence.** An item is done only when its own `done_when` evidence exists. "Mostly
   done", "in progress" and "planned" are open.
3. **A rollup that disagrees with the count is a finding.** If a position's own summary says more is done than the
   records show, list the difference.
4. **Gaps nobody raises are checked again** (§8.2 (5)): each gap the head kept as a decision at step 6, and whether
   it moved.
